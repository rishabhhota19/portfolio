- An IoT-enabled home-assessment system that combines sensor data, symptom checklists, and X-ray/CT analysis using deep learning and rule-based logic.
- **Stage one** gives a preliminary assessment from vitals and symptoms. **Stage two** adds chest X-ray analysis for a deeper diagnosis.
- A guided UI:
  - **Phase 1** asks screening questions.
  - **Phase 2**, if needed, asks for a chest X-ray upload.
  - A final rule-based engine combines all inputs into a report with recommended next steps.
- Awarded 6th place college-wide. Related papers are listed under Publications.
